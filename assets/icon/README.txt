OPEN CAPTURE EXPRESS — OPENSTAGE SUITE ICON

OpenCapture_Express.svg: editable vector master for a vector drawing program.
OpenCapture_Express.png: PNG at 2048 x 2048 pixels.
OpenCapture_Express.ico: Windows icon with 16, 32, 48, 64, 128, and 256 pixel images.
PNG/: individual PNG exports at 16, 32, 48, 64, 128, 256, 512, and 1024 pixels.

The approved OpenCapture viewfinder is retained. A rounded lowercase e at
the center identifies the Express version. The letter is drawn as editable
paths and requires no installed font.
Indigo accent: #9CA5FF to #7D87F2.
Navy tile: #102037 to #0B172A.
Space outside the rounded tile is transparent.

The SVG has a 1024 x 1024 artboard, separately named Tile and Symbol groups,
editable paths, live strokes, and vector gradients. It contains no embedded
raster images, fonts, or linked assets. It scales without resolution loss.
Open the SVG in a vector drawing program and Save As .ai for an native copy.

Validation: SVG parsed and checked for vector-only artwork; PNG dimensions
and transparency checked; ICO checked for all six intended sizes; design
and small-size renders visually inspected. a vector drawing program and Windows
